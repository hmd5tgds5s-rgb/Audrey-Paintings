# Audrey Paintings

Portfolio and shop site for Audrey's original paintings: gallery, prints, originals and pet-portrait commissions, with a frame/lighting preview and "View on your wall" AR for every piece.

- Static site: `index.html` plus images in `art/` (full size) and `art/thumb/` (gallery thumbnails).
- Paintings, sizes and prices are listed near the top of the script in `index.html` (`ART`, `PRINTS`, `COMMISSIONS`).
- Sizes are in inches and drive the true-scale AR model, so keep them accurate.
